What the price does not include.

  • Prices exclude VAT, licences, third-party API costs, payment service provider fees and travel expenses.
  • A 30–50% advance payment applies before the project starts.
  • Fixed-price projects define functions, integrations, user numbers and acceptance criteria.
  • Additional work is approved through a written change request.
  • Data migration, data cleansing and manual classification are priced separately.
  • For AI projects, model costs, API usage, data storage and human oversight are defined separately.
  • Support contracts define support hours, response times and severity levels.

The prices on this page are positioning guidance for the European market, not an offer. Prices are reviewed before every significant proposal, taking into account the client's country, system complexity, data quality, level of responsibility and the actual project scope.
