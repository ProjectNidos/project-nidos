Settings

Values the site and CRM read at runtime
Site password gate
Shows a password prompt over the public site before any content loads.
This gate runs in the visitor's browser, so the password is delivered to everyone who loads the page and can be read from the source. It keeps casual visitors out of an unfinished site. It is not access control, and nothing behind it should be private.
Contact form categories
Maps the value each option on the public contact form sends to the category the CRM files the enquiry under. The value on the left has to match the form exactly — when it drifts, enquiries quietly land in the uncategorised bucket instead.
Pipeline stage names
What each stage is called in the CRM. The underlying stage ids are fixed — every lead already stores one.
Notification addresses
Who to tell when a website enquiry arrives, one address per line. Stored now; nothing sends mail yet.
